LoL 信号盘 · Edge / Chrome 扩展
==========================================================

用法（只用这一种交互）
----------------------
  按住 G 不放          → 信号盘在光标处弹出
  移动鼠标滑向某方向   → 对应扇形高亮，中心同步显示图标与名称
  松开 G               → 在光标位置发出所选信号
  Esc 或 鼠标右键      → 取消，不发出
  呼出后也可用方向键选（可选）

为什么只保留 G
--------------
其余触发方式（Alt/Ctrl + 左键、单独按住 Alt、轻点 G/V）默认全部关闭，
避免和你访问的网站抢按键。输入框里按 G 会自动让路，不会抢你打字。
想改：编辑 content.js，把对应参数设成 true 即可。

生效范围
--------
· 只在普通网页（http/https）生效：edge:// 开头的页面、Edge 新标签页、
  PDF 阅读器、扩展商店页面都不会生效
· 装好之后**已经打开的页面要按 F5 刷新**才会生效（内容脚本只在页面加载时注入）
· 想让本地 HTML 文件也生效：edge://extensions → 本扩展 → 详细信息 →
  打开「允许访问文件 URL」

文件说明
--------
manifest.json       扩展清单（不需要任何特殊权限）
content.js          挂载配置：半径 / 语言 / 配色 / 按键都改这里
lol-ping-wheel.js   组件本体

改过 content.js 或 lol-ping-wheel.js 之后，到 edge://extensions 点一下
本扩展的「重新加载」。

卸载
----
edge://extensions → 找到「LoL 信号盘」→ 移除。
